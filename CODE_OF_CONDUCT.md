# Code of conduct

PrintBridge is made for ordinary offices, and everyone is welcome to help, whatever their experience, language or background.

**Please:**
- be kind and patient, especially with people who are new to GitHub or to coding
- talk about the work, not the person
- assume good intent, and say clearly when something isn't right

**Not accepted:** insults, harassment, unwanted personal attention, discriminatory jokes or language, or publishing someone's private details.

If someone breaks this, the maintainer may remove their comments, issues or pull requests, and block them from the project.

**To report a problem with someone's behaviour**, send a message to [@devnithdev](https://github.com/devnithdev) on GitHub. If you would rather not post anything public, use [private reporting](https://github.com/devnithdev/printbridge/security/advisories/new) and say it is about conduct, not a security problem. Reports are kept private.

Based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
