Printing from anywhere (remote codes)

Give a few chosen people a personal code. They open PrintBridge’s online drop page from anywhere, type the code and send a file; this computer collects it and prints it. Files are locked in their browser and only this computer can unlock them.

To connect the drop page or add people, open this page on the main computer itself.
🔒 Remote printing settings are locked. Type the lock code to see or change the people, their limits and the drop page.
