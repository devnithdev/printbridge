PrintBridge is installed

The setup page in your browser asks whether to start PrintBridge now or just close. If you closed it without starting, PrintBridge starts by itself the next time this Mac starts. To start it sooner, open the PrintBridge folder in Applications and choose Restart PrintBridge.

If the setup page did not open in your browser, choose Reconfigure PrintBridge in the same folder. It also has Open, Check and Uninstall.
